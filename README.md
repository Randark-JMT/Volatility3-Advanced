# Volatility 3 patched by CRONUS

## Plugin - pypykatz

```shell
vol.exe -f demo.vmem windows.vol_pypykatz.pypykatz
```

参考 [CRONUS-Security/Volatility3-pypykatz: pypykatz plugin for Volatility3 Framework](https://github.com/CRONUS-Security/Volatility3-pypykatz)

需要对 `pypykatz` 的源码进行修改
